Cloudflare 镜像把已提交的图片额外复制到一个 R2 存储桶，供自定义域或公开地址访问。GitHub 仍是唯一发布来源；不开启时所有原有功能保持不变。

当前没有可配置的 GitHub 仓库成员。Cloudflare 只适用于 GitHub 仓库；本地仓库不支持镜像。

请先在 Cloudflare 为该存储桶绑定自定义域，并确认 DNS、证书与缓存策略已生效。`r2.dev` 公共开发地址只有在实际验证可访问后才使用；自定义域验证通过后，可在 Cloudflare 关闭 `r2.dev` 公共访问，避免留下第二个公开入口。TOUKO 不会自动开启、关闭或改动 Cloudflare 配置。
