连接你的仓库

图片和元数据保存在你自己的 Git 仓库里。TOUKO 只管理工作区，不接管你的凭据。

请先在 GitHub 创建图片仓库，并勾选添加 README。不要使用 TOUKO 的代码仓库存图片。

凭据留在服务端

写入 GitHub 需要先在启动 TOUKO 的终端里设置 GITHUB_TOKEN，并授予目标仓库 Contents 读写权限，然后重启服务。这个页面不接收、也不保存 token。

尚未检查凭据

一个工作区只连接一个仓库。要换仓库，请用新的 --state-dir 重新启动服务；已有缓存和待发布修改不会被覆盖。连上已有仓库后，请手动同步或初始化。
